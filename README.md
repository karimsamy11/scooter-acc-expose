## Engineering Lab
https://karimsamy11.github.io/scooter-acc-expose/lab/ invites engineers to challenge the reference architecture. Visitors answer three short questions (idea, why it is better, how to test it; the first two required) and post them to GitHub Discussions themselves. Optionally, an AI model running in **their own** [Ollama](https://ollama.com) discusses the idea and expands it into an engineering review: architecture, FR-1 to FR-8 check, risks and assumptions, validation suggestions. The visitor can edit or leave out the review.

- No paid API, no server, no keys. The page talks only to `http://127.0.0.1` / `localhost` on the visitor's computer; the conversation never leaves their browser.
- The AI knows only the public brief in [`lab/knowledge/`](lab/knowledge/): no private code or documents. Edit those two files to change what it knows and how it behaves.
- Without Ollama (phones, Safari, no setup) the three-question form and Discussions still work.
- Visitor setup (Windows, macOS, Linux) is on the page. In short: install Ollama, `ollama pull qwen2.5:7b`, start a temporary lab session `OLLAMA_HOST=127.0.0.1:11435 OLLAMA_ORIGINS=https://karimsamy11.github.io ollama serve` (exact origin, no wildcard; access ends when the window closes), allow the browser's local-network prompt.

| File | Purpose |
|---|---|
| `lab/index.html`, `lab/lab.css`, `lab/lab.js` | page, style, UI logic |
| `lab/ollama.js` | local Ollama client (loopback only, streaming, error kinds) |
| `lab/proposal.js` | the three questions, AI expansion prompt, parsing, Markdown, Discussions link |
| `lab/render.js` | safe Markdown subset rendered as DOM text (no `innerHTML`) |
| `lab/knowledge/system-prompt.md`, `engineering-brief.md` | the AI's rules and its only source of project facts |
| `tests/` | browser tests against mock Ollama servers: `python tests/run_tests.py` |

Owner setup, once: enable Discussions (Settings → Features), create a category named **Engineering proposals** (slug `engineering-proposals`), and optionally install [giscus](https://giscus.app) and put the repo and category IDs into `GISCUS` in `lab/lab.js`.

`index.html` is generated by `tools/build_expose_site.py` in the private repo. Do not edit it by hand; the `lab/` and `tests/` folders are edited here.
